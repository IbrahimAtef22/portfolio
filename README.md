## 🛠️ How to Run Locally

### Prerequisites
- Node.js (v18 or higher; v20+ recommended)
- npm or pnpm or yarn

### Steps

```bash
# 1. Clone or navigate to the project directory
cd "Ibrahim Atef Eltahlawy"

# 2. Install dependencies (if not already installed)
npm install

# 3. Start local development server
npm run dev
```

Visit the local URL shown in your terminal (usually `http://localhost:5173`).

### Production Build & Preview

```bash
# Check TypeScript types & build production bundle
npm run build

# Preview production build locally
npm run preview
```

## 🚢 Deployment Instructions

### Deploy to Vercel
1. Push this repository to your GitHub account.
2. Sign in to [Vercel](https://vercel.com) and click **Add New Project**.
3. Import this repository.
4. Framework Preset will auto-detect as **Vite**.
5. Click **Deploy**.

### Deploy to Netlify
1. Sign in to [Netlify](https://netlify.com) and select **Import from Git**.
2. Build command: `npm run build`
3. Publish directory: `dist`
4. Click **Deploy**.
